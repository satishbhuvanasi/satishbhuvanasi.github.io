# Satish Bhuvanasi — Professional Website

This is a portable, static multi-page website intended for GitHub Pages.

## Preview locally
Open `index.html` in a browser. All pages and styles are local; no build step, database, subscription, or external JavaScript dependency is required.

## Pages
- `index.html` — Home
- `journey.html` — Career journey
- `innovation.html` — Product and solution experience
- `perspective.html` — Transformation point of view
- `insights.html` — HLS Radar, HLS Explained and Industry Perspectives
- `connect.html` — Professional networking

## Publish to GitHub Pages
Copy the contents of this folder into the root of the personal repository `satishbhuvanasi.github.io`, then enable GitHub Pages from the repository's Settings > Pages. The repository should remain under the user's personal account.

## Before public launch
- Review every career description and metric.
- Replace LinkedIn placeholders with the exact profile and post URLs.
- Add the approved Agilisium business booking URL, if appropriate.
- Confirm the public wording for selected product/solution contributions.
- Keep an independent ZIP backup on a personal device.

The website is a static HTML/CSS/JS project and can be moved to another static hosting provider.
